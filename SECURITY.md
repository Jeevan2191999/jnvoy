# Security

## Reporting a vulnerability

Email **j.nagaraj2109@gmail.com** with the subject "Jnvoy security". Please do not open a public issue for a security problem.

I will acknowledge your report within two working days and tell you what I find. If the problem affects customers, I will tell them too.

Include what you found, how to reproduce it, and what you think the impact is. Testing against your own deployment is fine. Please do not access other customers' data, run denial-of-service tests against the hosted service, or test social engineering.

## What Jnvoy does and does not do

See the [security page](https://www.jnvoy.com/security) and the [privacy page](https://www.jnvoy.com/privacy). They list the services involved, what is stored, and what has not been done yet, including that there is no SOC 2 or ISO 27001 report and no independent penetration test.

## Supported versions

Only the latest release on `main` is supported.
