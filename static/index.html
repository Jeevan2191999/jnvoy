Built for production, not just demos

Everything you need to deploy AI safely in a regulated environment. Sensible defaults, and every setting is an environment variable. No vendor lock-in.

Microsoft Presidio detection

Enterprise-grade NLP-based PII detection. 20+ entity types. UK-specific recognisers for NHS numbers, NI numbers, UK postcodes, and sort codes.

Exact-match cache

Identical requests from the same API key return the stored answer instantly, with no model call. Matches are exact and scoped to each key, so a changed word or system prompt never returns someone else's answer.

Intelligent routing

Assigns the cheapest capable model to each query automatically. Simple questions go to Haiku. Complex ones go to Sonnet.

Persistent audit logs

Every API call permanently logged to PostgreSQL. Never stores raw PII. Queryable by date, provider, and PII type.

Compliance report PDF

One endpoint generates a PDF for your compliance team: what was detected and redacted, by type and period, with your company name on it.

API keys and rate limits

Every request needs a key. Client keys call the proxy. Separate admin keys unlock the audit log, reports and cache controls. Per-key rate limits stop runaway usage.

Provider health monitoring

An outage detector tracks each provider's successes and failures and shows them on a health endpoint, so you see a provider degrade before your users do.

Slack connector

Protects every message sent to any AI bot in your Slack workspace. Posts a compliance note showing what was detected.

Docker stack

One command starts the API and its PostgreSQL audit database, once your keys are set. Self-hostable on your own infrastructure.

Redacts people, not vocabulary

Names, contact details, financial and government identifiers, and credentials are redacted. Company names, places and dates stay readable so answers stay useful. One setting widens the scope when you need it.

Optional second-pass review

A small language model can re-read text that has already been redacted and flag identifiers the rules missed, such as internal codes. Off by default. Runs locally with Ollama, or through Anthropic, in which case that redacted text goes to Anthropic.

Prompt injection blocking

Every request is scanned for injection attempts before anything else happens. Blocked requests never reach the model.

Change one URL. Add one header.

No SDK to install. No configuration to learn. No architectural changes. Point your existing LLM calls at Jnvoy with your Jnvoy key and every request is automatically protected.

Anthropic Claude OpenAI GPT-4o
before.pyexposed
# direct to Anthropic
import anthropic

client = anthropic.Anthropic(
  api_key="sk-ant-..."
)

response = client.messages.create(
  model="claude-haiku-4-5",
  messages=[{
    "role": "user",
    "content": user_message  # raw PII
  }]
)
after.pyprotected
# through jnvoy: new URL, plus your jnvoy key
import httpx

response = httpx.post(
  "https://www.jnvoy.com/v1/proxy",
  headers={"x-api-key": JNVOY_API_KEY},
  json={
    "model": "claude-haiku-4-5",
    "provider": "anthropic",
    "messages": [{
      "role": "user",
      "content": user_message  # PII redacted
    }]
  }
)
