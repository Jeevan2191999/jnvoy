Built for production, not a demo

Presidio-grade detection

Enterprise NLP PII detection across 20+ entity types, with UK-specific recognisers built in.

Semantic cache

Similar queries return cached responses instantly, cutting LLM spend by 20 to 40 percent.

Intelligent routing

Simple queries route to the cheapest capable model. Complex ones go to a stronger one automatically.

Persistent audit log

Every call is written to PostgreSQL permanently. Raw PII is never stored, only type and count.

Compliance report

Multi-tenant keys

Automatic failover

before.pyexposed
# direct to Anthropic
import anthropic

client = anthropic.Anthropic(
  api_key="sk-ant-..."
)

response = client.messages.create(
  model="claude-haiku-4-5",
  messages=[{
    "role": "user",
    "content": user_message  # raw PII
  }]
)
after.pyprotected
# through jnvoy — one line changed
import httpx

response = httpx.post(
  "https://jnvoy.onrender.com/v1/proxy",
  json={
    "model": "claude-haiku-4-5",
    "provider": "anthropic",
    "messages": [{
      "role": "user",
      "content": user_message  # PII redacted
    }]
  }
)
