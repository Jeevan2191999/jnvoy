One proxy. Every LLM. Always private.

Jnvoy intercepts every LLM call before it leaves your system. Sensitive data is detected, replaced with tokens, and restored in the response. Nothing sensitive ever travels.

// features

Built for production, not just demos.

Everything you need to deploy AI safely in a regulated environment. No configuration required. No vendor lock-in.

🛡️

Microsoft Presidio detection

Enterprise-grade NLP-based PII detection. 20+ entity types. UK-specific recognisers for NHS numbers, NI numbers, UK postcodes, and sort codes.

⚡

Semantic cache

Similar queries return cached responses instantly. Saves 20–40% of LLM costs automatically without any configuration.

🗺️

Intelligent routing

Assigns the cheapest capable model to each query automatically. Simple questions go to Haiku. Complex ones go to Sonnet.

📊

Persistent audit logs

Every API call permanently logged to PostgreSQL. Never stores raw PII. Queryable by date, provider, and PII type.

📄

Compliance report PDF

One endpoint generates an FCA and GDPR-ready PDF proving zero sensitive data was transmitted. With your company name on it.

🔑

Multi-tenant API keys

Each company gets complete data isolation. Their traffic, audit logs, and compliance reports are entirely separate.

🔄

Automatic failover

Outage detector tracks provider health. If Claude goes down, traffic automatically reroutes to GPT-4o or Gemini.

💬

Slack connector

Protects every message sent to any AI bot in your Slack workspace. Posts a compliance note showing what was detected.

🐳

Docker stack

One command starts everything. API plus PostgreSQL plus Redis. Self-hostable on your own infrastructure.

before.py 
# Before Jnvoy
import anthropic

client = anthropic.Anthropic(
  api_key="sk-ant-..."
)

response = client.messages.create(
  model="claude-haiku-4-5",
  messages=[{
    "role": "user",
    "content": user_message # ⚠️ raw PII
  }]
)
after.py ✓ protected 
# After Jnvoy — one line changed
import httpx

response = httpx.post(
  "https://jnvoy.onrender.com/v1/proxy",
  json={
    "model": "claude-haiku-4-5",
    "provider": "anthropic",
    "messages": [{
      "role": "user",
      "content": user_message # ✓ PII redacted
    }]
  }
)
