Accuracy

How well Jnvoy hides personal data, measured on example text we wrote ourselves. The misses are listed, and so are the limits of the test.

Last measured 27 October 2026 on version 3.0

The result

On a fresh set of examples written after our last round of fixes, with no rule changed after seeing its results, Jnvoy hid 22 of 25 sensitive values (88.0%) and left 17 of 17 harmless words (100.0%) readable. That is a good result for a first pass and it is not a guarantee: do not rely on any redaction tool as your only control.

A value counts as hidden only if neither the whole value nor any recognisable part of it (a surname, the last digits of a number) is still visible in the redacted text. These are first-pass results: the optional second check is off on the hosted service.

Speed on these short texts (35 to 50 characters each) was 16 to 32 milliseconds each in a small cloud container. We have not measured longer texts or the hosted service under load.

What it gets wrong

Sensitive values it still misses

  • A named house or barn with no flat number or "The" in front, such as "Rose Cottage, Mill Lane" or "Willow Barn, Stoke Road".
  • A French address with "bis" after the number, such as "8 bis rue des Lilas".
  • A Portuguese street-first address, such as "Rua das Flores 88".
  • An uncommon name in a list of attendees. The other two names in the list were hidden.

Harmless text it hid by mistake

  • A Unix timestamp that looks like an NHS number.
  • The words "Downing Street", read as a street address.
  • The word "Pepper", read as a person's name.
  • The city name "Lisboa", read as a person.
  • A link to public documentation, hidden as a web address.

Hiding too much costs you a slightly worse prompt. Hiding too little is the serious error, and the missed values above are the ones to watch.

Limits of this test

  • Written by us. The examples are synthetic text from the person who built the tool. This is not an independent evaluation.
  • Small. 25 sensitive values in the fresh held-out set is a gauge, not a statistical measurement. Expect real figures to differ in either direction.
  • Mostly English, mostly short. Names are detected best in English, and street addresses best in UK and US formats.
  • Country identifiers were tested only on published sample numbers. Accuracy on real data in those countries has not been measured.
  • No real customer data was used. Every value is invented or a documented example number.
  • Library versions matter. These numbers were measured with the versions the hosted service uses (Python 3.12, spaCy 3.7.5 and its en_core_web_lg 3.7.1 model). Newer versions scored one or two values differently in our checks.
  • It will change. The sets and the scores are kept in the repository, and a test fails if this page and the measured numbers disagree.

Repeat it yourself

The data and the script are in the evaluation folder. After installing the requirements, run python evaluation/run_eval.py --dataset evaluation/holdout3.jsonl --misses to see the table above and every value that leaked. If you find text it should have caught, open an issue with a made-up example of the same shape.
